Read the indicator, then read the context.

Observation periods differ: a monthly statistic can describe an earlier month while an exchange rate describes a business day. Each card shows its own period and source. Small charts scale independently and do not imply comparable magnitudes. Changes are from the previous available observation; rates use percentage points.

Inflation is computed from the same month's CPI one year earlier. Housing starts are an annualized pace, not completed homes. Exchange rates are indicative, not transaction quotes. New releases can revise earlier observations; this snapshot represents the current source vintage, not the values originally published.
